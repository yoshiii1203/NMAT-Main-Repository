# CHED Compliance Dashboard

Data-driven evidence for the NMAT cut-off policy (CMO No. __, s. 2026).

## Quick Start

```bash
# Clone repository and navigate to dashboard directory
cd NMAT_Analysis/streamlit_dashboard/CHED_relevant_dashboard

# Install dependencies
pip install -r requirements.txt

# Run the dashboard
streamlit run dashboard.py
```

## Data Requirements

Place `NMAT_Exodus.parquet` in one of:
- Same directory as `dashboard.py` (`streamlit_dashboard/CHED_relevant_dashboard/`)
- `dataset/` subdirectory of the repo root

The parquet file is the Pipeline 4 output (178,927 rows x 54 columns) integrating NMAT scores, PLE linkage, and citizenship classifications.

## Dashboard Tabs

| Tab | Description |
|-----|-------------|
| 1. Overview | Policy context, key headline metrics, how to use |
| 2. National Benchmark | NMAT-PLE linkage rates with 5-year rolling average |
| 3. Cut-Off Scenarios | 30th vs 40th percentile threshold comparison |
| 4. Per-HEI Analysis | Institution-level score distributions and PLE linkage |
| 5. Foreign Students | Foreign examinee profiles and SUC slot analysis |
| 6. Demographics | Breakdowns by sex and course group |
| 7. PLE Alignment | Linkage rates by percentile bin and institution type |
| 8. Trends | Historical score and volume trends (2006-2018) |
| 9. Accountability Framework | PHEI risk flags, monitoring template, transition timeline |
| 10. Data Appendix | Methodology, cohort definitions, glossary, limitations |

## Deployment on Streamlit Cloud

1. Push the repository to GitHub
2. Go to [share.streamlit.io](https://share.streamlit.io)
3. Connect your GitHub repo
4. Set the main file path to `streamlit_dashboard/CHED_relevant_dashboard/dashboard.py`
5. Deploy

The app will auto-detect `NMAT_Exodus.parquet` from the repository if placed in `dataset/`.

## Data Source

NMAT_Exodus.parquet is generated by Pipeline 4 of the NMAT Analysis pipeline. See the main repository README for the full pipeline documentation.
